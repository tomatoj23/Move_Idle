## 1. 遭遇形态（拍板）

- **遭遇 = 数值层一次「玩家 vs 一批怪」的战斗**：同屏怪数量由内容定，胜利条件 = 玩家存活且全场怪清空；玩家 hp 归零即失败（哪怕只剩最后一只怪）。
- 内容载体：`zone.encounters` 元素从裸 monster ref 升级为 `{ monster, count }`（count 可省略、缺省 1，上限 5）；boss 仍为单个 ref（固定单挑，count 恒 1，难度阶解锁与目标掉落锚点不变）。
- 「波次」术语消解：遭遇内不分批——分批在数值层等价于多个单怪遭遇串联，无独立语义；区域遭遇清单即全部编排。
- schema 为 v1 就地修订（内容库仅 1 个 zone 示例，无兼容负担）；版本仍住 `$id`。

## 2. 数值层群战语义

### 2.1 tick 与目标

- 100ms tick 不变；Combatant 泛化为「玩家 + 怪物数组」，各自独立 `next_attack_tick` 计时（#7「双方独立计时」的直接泛化）。
- 同 tick 多个 combatant 到点：先玩家、后怪物按站位序（站位序 = encounters 清单内序）；确定性顺序保证离线模拟同输入同输出。
- 怪物全部攻击玩家（无仇恨系统）；玩家目标 = 最靠前的存活怪（first-alive）。

### 2.2 事件模型（载荷封闭，零回调不变）

- `on_attack` 载荷不变；AOE 表达为逐目标多条 on_attack（每个受击怪一条），`skill` 字段携带来源（如 explode_fire）。
- 每只怪死亡各发一条 `on_kill { killer, victim }`，掉落链逐怪各走（#8 契约不变）。
- **连锁**：爆炸炸死怪 → 该怪 on_kill → 玩家 proc_on_kill 再 roll → 可再爆；链式允许、无深度上限（20% 级别的 roll 率天然收敛），数值观察期后再调。
- proc_on_hit 仍单目标（当前攻击目标）；群伤唯一入口是 proc_on_kill 的 explode_fire。

### 2.3 explode_fire 伤害语义（恢复，schema 零变更）

- 触发：目标死亡时按 `chance_percent` roll → 对**场内其余全部存活怪**造成 `击杀者攻击力 × amount_percent% × 火焰系数`，floor 最低 1，**不吃暴击**（与 proc_on_hit 的 v1 简化口径一致）。
- 元素固定 fire（effect 名即语义）；`amount_percent` = 击杀者攻击力百分比（与 proc_on_hit 的 damage_percent 同构）。
- 表现层爆炸演出保留，新增受击飘字（表现细节归雾区）。

## 3. 掉落衔接（#8 零改动）

- 三层判定链按每只怪独立走：多怪场 = 逐怪掉落判定，规则零改动。
- #8 平衡锚点重述：「掉落频率 = 击杀频率」仍成立，产出节奏由内容供给调节。
- 区域内容供给建议（替代 #5 §2 的「5~10 场」）：普通遭遇 3~6 场、单场 count 1~5、**总普通怪数建议 10~20 只**；首领单挑。

## 4. run_encounter 接口（语言无关，v2 草案）

```
run_encounter(player: {StatTable, hp}, monsters: StatTable[],  // 有序，即站位序
              skill_config) -> { result: win|lose,
                                 duration_ticks, events: Event[] }
```

- 签名变化仅一处：monster 单数 → monsters 有序数组；事件流与胜利语义如 §2。
- 离线（#9）与编辑器试算（#10）的同构复用自动继承：多怪遭遇在离线照常逐场模拟；挂机点可赢保证（#5 回退规则）不受影响——遭遇失败即整体失败，回退逻辑零改动。

## 5. 表现层约束（程序化特效路线）

- 站位 = 清单序展开（横排 / 纵向队列由表现层自定），数值层只传顺序；first-alive 的表现对应「打最前面的」。
- 同屏怪数上限 5 由 schema 承载，表现成本有界；增援/入场演出属表现自由度（数值层无排队概念）。
- 走图映射不变：玩家位置 = 遭遇清单下标。

## 6. v1 排除（进雾区）

- 精英/稀有变体（怪物修饰符）接入遭遇构成：schema 与校验管线已就绪，接入是纯引擎/规则增量，真实平衡需求出现再开（雾区单列）。
- 怪物侧 AOE / 玩家群体 debuff 等反向群战语义。
- 遭遇内分批/增援的数值语义。

## 范围边界

## 1. 结构总纲：区域制 + 难度阶

- 骨架是**区域链**：区域按 `order` 序号线性解锁，推进 = 依次打通区域。
- 每个区域可挂多个**难度阶**：同一区域重复挑战，怪物与掉落随阶缩放。重刷价值双轨：目标掉落（哪片区域、哪个首领掉什么）+ 阶位爬升（ilvl 抬升解锁词缀档位）。
- 无尽爬塔（深度爬塔）不进 MVP；若未来要做，属于新玩法模式，从雾区另行立项，不影响本结构。

## 2. 区域与遭遇

> ⚠️ 本节「一场遭遇 = 一个怪」已被 `multi-monster-encounters.md` 升级：遭遇 = 玩家 vs 一批同屏怪（`{monster, count}`，count ≤5，boss 单挑）；区域长度建议改为 3~6 场、总普通怪 10~20。

- 区域是内容单元（zone 对象，见 §7）：**固定有序普通遭遇清单 + 首领收尾**。
- 遭遇沿用 #7 的单怪轮番制：一场遭遇 = 一个怪。区域长度不限（建议 5~10 场普通 + 1 首领）。
- 走图表现直接映射内容：玩家位置 = 遭遇清单下标，清单走完打首领。表现层不参与判定。

## 3. 难度阶与 ilvl

- 区域内容只存**基准档**（第 0 阶）数据；缩放是引擎全局规则：
  - 第 n 阶怪物属性 = 基准 stats × 档乘数^n（乘数归引擎常量）。
  - 第 n 阶**有效等级 = 区域 level + n × 步长**（步长归引擎常量）。
- 怪物不引入「等级」概念，stats 存绝对值（配方模型既定原则：内容给离散数据，公式归引擎）。
- **掉落锚点（交给 #8）**：物品 ilvl = 击杀怪物的有效等级 = 区域 level + 阶位 × 步长。这是 ilvl 的唯一来源，词缀档位门槛直接挂在这上面。

## 4. 推进、卡关与回退

- 区域链推进：击杀首领 = 区域通关 → 解锁 `order + 1` 区域。在线自动沿链推进。
- 难度阶解锁：击杀某区域第 n 阶首领 → 解锁该区域第 n+1 阶。两维解锁都由首领承载。
- **卡关回退（永不挂起）**：遭遇失败 → 退当前区域起点重刷；当前区域起点再败 → 退上一区域起点。连续失败计数等实现细节归引擎。
- 回退规则是放置游戏生命线：保证任何时刻都存在一个稳定可赢的产出地点。

## 5. 挂机点（离线衔接契约，交给 #9）

- **挂机点** = 玩家自选的 {区域, 难度阶} 组合（限已解锁）。刷旧区域刷装备是合法且被鼓励的策略。
- 在线推进失败时，回退落点即挂机点；挂机点永远可赢（§4 保证）。
- **离线不推进进度**：离线 = 在挂机点反复 `run_encounter` 产出事件流（on_attack/on_kill），收益折算规则归 #9。
- 交给 #9 的接口：挂机点状态 `{zone_id, tier}` + 「该点可赢」的回退保证。

## 6. 角色等级与成长

- 有角色等级：击杀得经验（经验量 ∝ 怪物有效等级，公式归引擎），升级抬升玩家初始属性集（max_hp / attack_power 等基准）。
- 成长定位：等级管平滑成长与早期体验，**装备词缀主导强度**。基准值表用简单分段线性，归引擎常量。
- 角色等级不参与 ilvl（ilvl 只由 §3 的有效等级决定）。

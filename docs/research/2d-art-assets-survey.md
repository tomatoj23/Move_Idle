## 1. 需求锚点（来自 CONTEXT.md 与票面）

- 项目：Move_Idle = 2D 横版放置 ARPG，暗黑西幻（Diablo 式刷装备），个人项目、不排除未来上架。
- 表现层需求：主角横版行走/攻击/受击动画、怪物、装备/掉落特效、图标。
- 架构约束（CONTEXT.md）：**表现层**只负责可视化、不参与战斗判定；**内容数据**与引擎解耦。
  → 资源选型是纯表现层事务，可以整体替换；占位策略应以「动画命名约定 + 帧结构约定」为接口。

## 2. 评估标准

1. 许可证：个人可用 + 未来商业发布余地（CC0 > CC-BY/OGA-BY > 自定义许可 > CC-BY-SA 灰区）。
2. 横版行走 / 攻击 / 受击动画完整度（缺受击/死亡帧的资源要扣分）。
3. 暗黑西幻风格资源量。
4. 成套统一风格可行性（单作者/单包 > 跨包拼贴）。
5. 装备掉落特效与图标类资源可用性。

## 3. 分源调查

### 3.1 Kenney（kenney.nl）

- **许可证**：全站资产 CC0 1.0，个人与商用皆可、无需署名【高，长期政策】。
- **风格**：明亮、扁平、卡通风。与暗黑西幻**不匹配**，不适合当主角/怪物正式美术。
- **动画完整度**：横版平台类资源包有行走循环；攻击帧稀少、基本无受击帧【中】。
- **对本项目的价值**：占位与配角素材——UI 元素、粒子特效占位（Particle Pack）、通用图标。选它的理由只有一个：CC0 带来的零法律负担。

### 3.2 itch.io 免费区（itch.io/game-assets/free）

- **许可证机制**：每个资产页有独立 License 区块（CC0 / CC-BY / 自定义均存在），必须逐个核【高（机制层面）】。
- **风格与资源量**：横版动作/平台素材的高产地；免费区存在偏暗的中世纪/暗黑向角色与怪物包，是四个来源中「暗黑西幻 + 横版 + 动画完整」三条件交集最大的【中】。
- **动画完整度**：以知名免费作者为例（均为【待核】的具体条目）：
  - LuizMelo 系列（如 Medieval Warrior、Monsters Creatures Fantasy）：侧视角 Idle / Run / Attack(多段) / Hurt / Death 成套 spritesheet，带武器分层，是免费区动画完整度标杆【中，包名与许可待核】。
  - Pixel Frog「Tiny Swords」：CC0、完成度极高，但画风明亮，暗黑味不足【中】。
- **掉落特效与图标**：免费区有大量 VFX 与图标包，但质量/许可高度分散【待核】。
- **风险**：免费包常为付费包精简版；许可异质导致审计成本随包数线性增长。

### 3.3 OpenGameArt（opengameart.org）

- **许可证**：逐资产标注，平台支持 CC0 / CC-BY / CC-BY-SA / OGA-BY 3.0 / GPL 筛选【高（机制层面）】。OGA-BY 3.0 = 署名即可商用【中】；CC-BY-SA 用于游戏美术在「衍生作品 vs 集合作品」上存在法务灰区。
- **风格与资源量**：聚合站，总量最大、质量参差最大；横版暗黑西幻**成套**资源罕见，现实路径是跨包拼贴 → **成套统一风格可行性差**【中】。
- **对本项目的价值**：兜底与补充源；按「许可 = CC0/CC-BY/OGA-BY + 关键词 side-view / dark fantasy」定向检索。

### 3.4 CraftPix 免费层（craftpix.net/free/）

- **许可证**：自有 EULA（非 CC）。要点：可用于商业游戏、无需署名；**禁止将资产本身再分发/转售/重新打包**。以官网许可协议页现行文本为准【中，原文待核】。
- **风格与资源量**：暗黑向角色包、数百枚级 RPG 图标包、魔法/命中 VFX 包均有免费层条目；成套感是四源中最好的【中】。注意 CraftPix 聚合多位作者，跨包混用仍会风格漂移。
- **动画完整度**：免费角色包通常含 Idle / Run / Attack / Death，受击帧不如 itch 知名包齐全【中】。
- **风险**：自定义许可存在「站点改条款」的许可漂移风险；免费包与付费包边界需逐包确认。

## 5. 推荐组合候选（供决策票，不拍板）

- **组合 A「全 CC0 保险牌」**：Kenney（UI/特效占位）+ LuizMelo CC0 角色/怪物包（待核）+ OGA CC0 特效。优点：未来上架零许可负担；缺点：暗黑味不足，正式美术需整体替换。
- **组合 B「风格优先」**：CraftPix 免费层角色 + 图标 + VFX。优点：与暗黑西幻气质最贴、图标量最大、成套感最好；缺点：自定义许可 + 逐包审计 + 许可漂移风险。
- **组合 C「混合平衡」**：CC0 角色动画（主角/怪物走 itch 免费包）+ CraftPix 图标/特效。优点：核心动画许可干净；缺点：许可异质、需两套审计流程。
- **与架构的对齐建议**：无论选哪个组合，占位资源都应遵守「动画命名约定（idle / run / attack_N / hurt / death）+ 帧尺寸约定」，把「换正式美术」变成接口替换而非返工；图标 id 只存在于内容数据，表现层负责映射，保证图标源可整体更换。

## 6. 风险与法律注意

1. **许可漂移**：CraftPix/itch 自定义许可可随站点政策变化；采信前存档许可文本快照。
2. **免费包 = 付费包精简版**：混用免费层可能造成风格断口。
3. **CC-BY-SA 灰区**：游戏美术采用 CC-BY-SA 时，「游戏是否构成衍生作品」存在争议；个人项目风险可控，未来上架/接发行需过法务（分析性意见，非法律意见）。
4. **上架平台要求**：Steam 等平台要求提交方对全部资产持有使用权；CC0/CC-BY（保留署名清单）最稳，署名清单应从 MVP 起就维护。
5. **跨包拼贴**：四源中只有 CraftPix（同作者单包）与 itch 知名作者系列具备「成套」能力。

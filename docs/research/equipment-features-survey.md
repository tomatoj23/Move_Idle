# 调研：D3/D4/PoE 装备特性全景（对标 MVP 装备特性丰富度）

- 票：#17｜日期：2026-09-03｜决议输入：#13 第一轮拍板（纯装备驱动 / 基础技能常量保留 / 原型线验收 K=4）、#4 内容 schema、#8 掉落与稀有度
- 状态：调研定稿，待 #13 第二轮拍板 MVP 装备特性清单

## 调研范围与方法

- 对象：暗黑破坏神 3（2.7.x 终版，已停更）、暗黑破坏神 4（含资料片与当前赛季机制）、流放之路 PoE1（3.x 时代）、流放之路 PoE2（EA 现状）。
- 方法：领域知识整理 + web_search 核证易变事实（PoE2 词缀上限、Augment Sockets 现状、D4 Codex of Power 现状），关键核证来源见 §5。
- 视角：只看「装备上能长出什么、它们怎么改变 build」。全局伤害机制（D4 压制/易伤等）属战斗模型（#7 管辖），不在本报告。

## 1. 四作装备特性全景

### 1.1 D3（暗黑破坏神 3）

- **稀有度五档**：普通 / 魔法 / 稀有 / 传奇 / 套装。
- **传奇威能**：每件传奇固定携带一条专属威能词缀，是 build 的直接来源——改变技能机制（某技能伤害 ×N、机制替换、条件触发器），数量以千计。
- **套装**：2 / 4 / 6 件套阶梯效果；6 件套通常是 build 地基（几十倍伤害的专属加成），与传奇威能共同构成「套装决定骨架、威能决定细节」的 build 结构。
- **卡奈魔盒（Kanai's Cube）**：萃取传奇威能（脱离装备本体自由装配，武器/护甲/首饰各 1 槽）、重铸传奇、升级稀有、套装件转换。
- **附魔（Mystic）**：对已得装备重 roll 一条词缀（洗练）。
- **传奇宝石**：插在首饰上的独立成长系统（0~150 级，专属升级通道），携带特殊效果（增伤 / 减伤 / 特殊触发）。
- 其他：Ramaladni's Gift（给武器打孔）等消耗品。

### 1.2 D4（暗黑破坏神 4）

- **稀有度五档**：普通 / 魔法 / 稀有 / 传奇 / 独特。
- **威能（Aspects）**：传奇装备携带的「玩法改变级」词缀，是 D4 的 build 主轴。**威能可从装备上提取**——
  - **Codex of Power（威能典籍）**：地下城首次通关系数解锁对应威能，永久入库、可无限次铭刻到装备上（数值为保守基线）；
  - **直接提取**：摧毁传奇装备提取其威能，数值随机（通常更高），一次性使用。
- **独特（Uniques）**：固定词缀不可重 roll，携带全局改变玩法的独特效果（build-around 定向极强），稀有掉落。
- **附魔（Occultist）**：重 roll 一条词缀（给出两个候选选一替换）。
- **词缀池**：核心四属性（力敏智意志）+ 攻/防/资源/移动/实用分类，含「+某技能等级 / +某类别技能等级」类词缀（依赖技能系统）。
- **插槽系统**：宝石 + 后续赛季加入的符文之语。
- 其他：装备品质分层（普通/神圣/先祖）与物品等级门槛联动。

### 1.3 PoE1（流放之路 1）

- **稀有度四档**：普通 / 魔法（2 条：1 前 1 后）/ 稀有（6 条：3 前 3 后）/ 暗金（unique）。核证：poedb Glossary。
- **词缀池 × 档位**：每类基底数百条词缀，按 tier 分档、受物品等级门槛约束——本项目「档位」概念即源于此。
- **基底（base types）与隐式词缀（implicit）**：同类装备几十种基底决定词缀池方向；基底自带固定隐式词缀（如武器天生伤害、护甲天生护甲值）。
- **暗金（unique）**：约 1195 个（核证：poewiki 2026-08），固定词缀 + 强 build-around 特效，社区定位「暗金是新玩法入口」；数值多为固定或极小浮动。
- **手工 crafting 体系**：改造/增幅/混沌/崇高/神圣/剥离/化石/精髓/收割/腐化（Vaal，一次性不可逆改写）等——属装备加工玩法，深度极高。
- **影响类词缀组**（influence，塑界/裂隙等）：额外特殊词缀池。
- 不适用项：珠宝插天赋树、六连技能宝石联动——均依赖技能/天赋系统，与本项目 #13 拍板（纯装备驱动）互斥。

### 1.4 PoE2（EA 现状）

- **稀有度四档**：普通 / 魔法（2 条：1 前 1 后）/ 稀有（6 条：3 前 3 后）/ 暗金。核证：poe2wiki Modifier 页（2025-08 更新，与 PoE1 同构）。
- **Augment Sockets（原符文插槽）**：武器与护甲自带插槽，可插符文（runes）/ 魂核（Soul Cores）/ 圣像（Idols）等 augment 物品提供固定加成，社区资料称已扩至 295+ 种（核证：poe2path 2026-08）。
- **暗金**：通常继承基底的隐式词缀 + 一个特殊效果（核证：poe2wiki Unique item），数量少而精。
- **词缀档位与物品等级门槛**：同 PoE1 逻辑；quality / 催化剂等强化手段保留。

## 2. 交叉提炼：装备特性的八种原类型

| # | 原类型 | 代表 | 本项目现状 |
|---|---|---|---|
| 1 | 数值词缀（属性数字） | 全作通用 | ✅ 已实现：stat 词缀 + 档位（#4/#8） |
| 2 | 玩法改变级特效词缀 | D3 传奇威能 / D4 威能 / PoE 暗金特效 | ✅ 已实现：传奇词缀四原语封闭集 + 10 条 roster（#8） |
| 3 | 基底差异化（含隐式词缀） | PoE/PoE2 基底与 implicit | ✅ 机制已就位：`implicit_mods`（固有属性）字段 + 首示例已用；差内容供给 |
| 4 | 套装 | D3 套装 / D4 | ❌ 未实现：需新内容类型 + 套装效果表达 |
| 5 | 插槽 + 镶嵌物 | D3 传奇宝石 / PoE2 符文 / D4 宝石符文 | ❌ 未实现：需新内容类型 + 穿脱管理 |
| 6 | 威能迁移 / 特效解耦 | D4 Codex of Power / D3 卡奈萃取 | ❌ 未实现：属装备管理玩法 |
| 7 | 装备加工 / 洗练 | D3 附魔 / D4 附魔 / PoE crafting | ❌ 未实现：核心循环外的再加工层 |
| 8 | 技能等级类词缀 | D4「+技能等级」/ PoE 宝石增强 | ❌ 排除：依赖技能系统，与 #13 拍板（纯装备驱动）互斥 |

术语对齐：PoE 的「隐式词缀 / implicit」在本项目已有对应物——术语表「装备基底」定义中的**固有属性**（schema 字段 `implicit_mods`）。下文一律用项目术语。

## 3. 映射评估（逐特性 × 本项目架构）

评估维度：schema 成本 / 数值层成本 / 离线同构（#9）/ 放置玩法适配 / 与既定拍板冲突。

| 特性 | MVP 适配结论 | 理由 |
|---|---|---|
| 传奇词缀扩容 | ✅ 建议（低成本） | 四原语封闭集已立（#8），扩容是内容供给不是机制变更；原型线（K=4）验收的主要抓手 |
| 固有属性供给扩容 | ✅ 建议（零 schema 成本） | `implicit_mods` 已在 schema v1 且示例已用；补齐首批基底的固有属性差异化即可，聚合逻辑（来源求和）不变 |
| 套装 | ⚠️ 可试点 / 可后置 | 需新内容类型 + 套装效果表达（复用原语或新原语 = schema 升版）；D3 式「套装 = build 地基」会与传奇词缀竞争 build 主导权；收集乐趣与放置玩法兼容 |
| 插槽 + 符文/宝石 | ⚠️ 建议后置 | 与传奇词缀功能高度重叠（都是「装备提供的外挂效果位」）；需新内容类型，且插槽管理依赖 #14 背包装备管理先行 |
| 威能迁移（Codex/萃取） | ⚠️ 建议后置 | 属装备管理玩法（依赖 #14/#15）；放置玩法下「手动装配威能」的主动操作收益存疑 |
| 装备加工 / 洗练 | ⚠️ 建议后置 | 核心循环（掉落 → 替换）之外的再加工层；洗练是回归后的主动操作，与「放置」定位弱兼容；PoE 式深度 crafting 体量远超 MVP |
| 技能等级词缀 | ❌ 排除 | 依赖技能系统，与 #13 Q1=A 拍板互斥；技能系统若未来毕业（雾区「技能系统内容化」）再议 |
| 全局伤害机制（压制/易伤） | ➖ 非本票 | 属战斗模型（#7 管辖），不是装备特性；若未来需要由 #7 修订承载 |

## 4. MVP 候选特性清单（供 #13 第二轮拍板）

- **C1 传奇词缀扩容**：roster 10 → 20+，覆盖四原语 × 多元素 × 多槽位，配合原型线验收。（内容供给）
- **C2 固有属性供给扩容**：首批基底配齐差异化固有属性，提升基底选择深度。（schema 零改动）
- **C3 套装试点**：1~2 套小规模套装进 MVP，或整体留 post-MVP。（中成本，schema 升版）
- **C4 插槽/符文**：建议明确写进雾区（post-MVP）。
- **C5 威能迁移 / 装备加工**：建议明确写进雾区（post-MVP）。
- **C6 技能等级词缀**：排除（与纯装备驱动互斥），随技能系统雾区一并观察。
